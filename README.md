# Modern Static Website Deployment

A fast, responsive static website built with pure HTML5/CSS3 and deployed to an AWS EC2 instance served via Nginx.

## 🚀 Features

* **Lightweight & Fast:** Pure HTML5 and modern CSS3 without external framework overhead.
* **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile displays.
* **Production Ready:** Configured for high-performance delivery using Nginx on AWS EC2.
